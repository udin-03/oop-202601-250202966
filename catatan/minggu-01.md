# Catatan Minggu 01: Paradigma Pemrograman dan Setup

## Yang saya kerjakan
Mempelajari cara menggunakan bahasa java. Menganti kode pada "HelloFungsional.java", "HelloOOP.java", dan "HelloProsedural.java" agar output yang dikeluarkan menghasilkan kalimat sapaan, nama dan NIM.

## Keputusan desain
Sapaan yang saya buat adalah seperti ini "Aset-Pinjam, Hallo nama saya " + nama + " (" + nim + ")". Semua paradigma saya buat outputnya sama seperti ini.

## Kendala
Kendala awal yang saya hadapi adalah ketika menjalankan perintah ".\scripts\uji.ps1" di PowerShell. Kendala tersebut diatasi dengan mengatur Execution Policy sesi PowerShell sehingga perintah bisa dijalankan.

## Penggunaan AI
- Alat yang dipakai: Gemini.
- Bagian yang dibantu AI: proses pembuatan kode.
- Prompt utama: saya menempelkan kode yang saya salin dari file "HelloFungsional.java", "HelloOOP.java", dan "HelloProsedural.java" untuk meminta dijelaskan tentang isi kodenya dan bagaimana cara agar bisa membuat output pada masing-masing kode tersebut berisi kalimat sapaan.
- Yang saya ubah atau tolak dari saran AI, dan alasannya: tidak ada yang saya ubah karena kode yang dibuat sudah cukup sederhana dan sesuai perintah.
- Satu hal yang saya pahami lebih baik sekarang: bisa menggunakan bahasa java untuk menjalankan program seperti "print" pada python.
